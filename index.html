From my first HTML/CSS steps to professional WordPress development.

I started my web development journey with HTML and CSS in January 2024. Soon after, I moved into PHP and began learning backend development, databases and application architecture.

In March 2024, I started learning Laravel. That experience gave me a strong foundation in MVC, Eloquent, authentication, APIs, MySQL and structured backend development. I later expanded into Vue.js and Inertia to understand modern full-stack application development.

After building that foundation, my focus shifted toward WordPress development. I now work with WordPress, WooCommerce, Elementor, PHP, JavaScript and custom plugin development — combining my backend knowledge with practical client-focused website work.
